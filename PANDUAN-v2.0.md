## Penting
Paket ini sengaja tidak menyertakan `assets/config.js`.
Jangan hapus file `assets/config.js` yang sudah aktif di repository GitHub karena file itu menyimpan:
- URL Apps Script BEING Voice
- Link LMS
- Link konsultasi
- Link dashboard lain

## Cara upload
1. Ekstrak ZIP.
2. Buka repository `dash-being`.
3. Pilih **Add file → Upload files**.
4. Upload seluruh isi hasil ekstrak ke root repository.
5. Jangan hapus `assets/config.js` yang sudah ada.
6. Commit dengan pesan:
   `Update BEING v2.0 floating WA`
7. Tunggu deployment terbaru menjadi hijau.
8. Buka:
   `https://beingpsikologi.com/?v=20`
